# Schermata di apertura

`splash.jpg`: immagine intera della schermata di apertura (logo, scritta, slogan e i sei personaggi), 926 x 2000 px.
Disegnata fuori dall'app e usata così com'è da `SplashView`. Lo slogan è dentro l'immagine, quindi resta in italiano in tutte le lingue.
Immagine generata dall'IA: controllare i termini d'uso per l'uso commerciale prima della pubblicazione.
Per una resa ancora più nitida sugli iPhone si può usare una versione più grande (per esempio 1290 x 2796 px), con lo stesso rapporto.
