# Prompt completi per le immagini dei coach

Ogni prompt è completo e si copia così com'è. Sono in inglese perché i generatori lo capiscono meglio. Non contengono nomi di persone. Per mantenere lo stesso volto, genera prima il "Benvenuto" di ciascun coach in più varianti, scegli la migliore e usala come immagine di riferimento (character reference) per gli altri prompt.

## Prompt negativo (uguale per tutti)

```
cartoon, 3d render, plastic skin, over-retouched, airbrushed, harsh shadows, stiff pose, forced grin, teeth too perfect, exaggerated expression, text, watermark, logo, extra fingers, deformed hands, celebrity likeness, uncanny valley, dark mood
```
